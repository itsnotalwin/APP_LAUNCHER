# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
The owner (itsnotalwin / alwinnewman97) and visitors who want to browse and open the owner's GitHub Pages sites, on phone (installed PWA) and desktop. [Inferred from the repo; not yet confirmed in an interview.]

## Product Purpose
One place to browse, filter and launch every GitHub Pages site for two GitHub profiles, with recently visited sites and per-repo branch and commit history. Success: any site opens in two taps.

## Capabilities and Constraints
Static single-file PWA (index.html, sw.js, manifest.json, SVG icons). Live data from the GitHub REST API (unauthenticated, rate-limited). Profile switcher, a-z / recent / stars sort, tag filter, search, explorer and launcher modes, light and dark themes. Preserve all behavior and copy.

## Brand Commitments
Name "Launchpad". Rebrand direction approved by the user from a reference image: monochrome, editorial serif, dot and hatch fields, black ink blob.

## Evidence on Hand
Real repo data comes from the GitHub API at runtime. No testimonials or metrics exist; none may be invented.
